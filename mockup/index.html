Overview

[[read|train.py:12|`train.py` is the only entry point]]. [[read|train.py:88-131|It builds the model, the data loader and the optimizer from one `Config`, then runs a fixed number of steps]].

[[read|model.py:9|The model is a 12-layer decoder-only transformer]]. [[read|model.py:30-44|Positions are rotary, not learned]]. [[test|tests/test_model.py:21|The token embedding and the output head share one weight matrix]].

[[read|data.py:18-26|Training data is pre-tokenized into `uint16` shards that the loader memory-maps, so no shard is ever loaded whole]]. [[inferred|data.py:52-55|Each GPU reads its own interleaved slice of every shard, so multi-GPU runs need no sampler]].

[[runtime|train.py:69-71|It trains in bf16 autocast on CUDA and in fp32 everywhere else]]. [[none|search:clip_grad|There is no gradient clipping]].

[[docs|README.md:31|The README reports 3.3 validation loss after about two hours on one H100]].
